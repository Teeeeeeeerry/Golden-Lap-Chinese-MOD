# 创意工坊引流物品

在 Steam 创意工坊放一个**只有说明、不含汉化内容**的物品，用来把玩家引到 GitHub 下载安装器（见 spec #1 Out of Scope：工坊仅作引流，不分发内容本体）。

## 物品内容

- **标题**：Golden Lap 简体中文汉化（说明页 / Chinese Localization Info）
- **描述**：`description.txt`（Steam BBCode 格式，直接粘贴）
- **预览图**：一张汉化后的游戏主菜单截图，自行截取，不放进仓库。
- **MOD 本体**：官方 MOD 系统要求物品是一个 MOD 文件夹。放一个最小的空 MOD 即可，不要放任何译文或游戏资源。玩家误启用它也不会影响游戏。

## 上传步骤（人工）

1. 按游戏官方 MOD 文档的要求，新建一个空的 MOD 文件夹，名称和简介写成说明页的标题。
2. 用游戏内 MOD 菜单（或官方提供的上传工具）把它上传到创意工坊，可见性先设为“仅自己可见”。
3. 在 Steam 物品页上粘贴 `description.txt`，上传预览图，确认链接指向项目的 Releases 页面。
4. 检查无误后改为“公开”。

每次发布新版本后，不需要更新工坊物品：链接始终指向最新的 Releases。
