[h1]Golden Lap 简体中文汉化（说明页）[/h1]

[b]本物品不含任何汉化内容，订阅它不会让游戏变成中文，也无需在游戏中启用。[/b]它只是一个说明页，指向 GitHub 上的汉化项目。

游戏自带的 MOD 系统只能加载数据文本和图片，无法替换界面文本和字体，所以汉化无法通过创意工坊分发。请到项目主页下载：

[url=https://github.com/Teeeeeeeerry/Golden-Lap-Chinese-MOD]https://github.com/Teeeeeeeerry/Golden-Lap-Chinese-MOD[/url]

[h2]汉化内容[/h2]
[list]
[*]菜单、赛事事件、内容说明和比赛界面（当前为机翻初稿，欢迎提交校对意见）
[*]车队名、赛道名、车手名保留英文
[*]中文使用游戏自带的思源黑体显示
[*]以「简体中文」顶替语言菜单中的「土耳其语」，安装后无法再使用土耳其语界面
[/list]

[h2]使用方法（macOS）[/h2]
需要 macOS 11 或更新版本，不用安装 Python。打开「终端」，粘贴下面这一行，按回车：
[code]/bin/bash -c "$(curl -fsSL https://github.com/Teeeeeeeerry/Golden-Lap-Chinese-MOD/releases/latest/download/install.sh)"[/code]
装好后进入游戏，在设置 → 语言里选择「简体中文」。

游戏更新后再运行一次这条命令即可。要恢复原版，在命令末尾加上 glzh restore。

也可以从 Releases 页面下载压缩包安装，步骤见项目主页。

[h2]使用方法（Windows）[/h2]
需要 Windows 10 或更新版本（64 位），不用安装 Python。到 Releases 页面下载文件名以 windows-x86_64.zip 结尾的发布包，退出游戏，完整解压后双击 install.bat。要恢复原版，双击 restore.bat。
