# 排行榜状态标签使用专用中文字体

**Status:** accepted（ADR 0003「不新增对象」的例外）

排位赛和正赛中，排行榜右侧的状态标签只剩深色底，文字看不见。排行榜面板用两层模板遮罩（Mask）裁出圆角，标签放在面板外，靠关闭 maskable 才露出来。Figtree 没有中文，TMP 把中文放进后备字体的子网格，子网格创建时不继承 maskable，于是被遮罩裁掉，不受裁剪的深色底还在。游戏的 TextMeshPro 程序集里没有任何地方设置子网格的 maskable。

决定：给标签配一份主字体就有中文字形的专用字体。注入时从 `NotoSansSC-Black SDF` 克隆出 `GoldenLapZH-StatusLabel SDF`，新增字体、材质、图集各一个对象，共用源字体文件，不开多图集，行度量对齐 Figtree，后备链沿用 Figtree-Bold。`resources.assets` 和 `ui_assets_all` 包各克隆一份：场景 `level2` 的 20 行标签引用前者，包内预制体的标签引用后者。标签同时清除样式绑定，因为 `FunTextTMP` 运行时会按样式把字体改回 Figtree。

理由：
- 现有思源黑体开了多图集（ADR 0003），字形落到第 2 张图集起同样走子网格，而全游戏的中文都在写这份字体，标签的字落在哪张图集无法保证，用久了问题还会回来。
- 专用字体只服务这几个短标签，一张 1024² 图集足够，中文始终在主网格里，遵守标签的 maskable。

**Considered Options:**
- **保留英文标签**（否决）：没有技术风险，但比赛界面留下英文。
- **预置关闭 maskable 的子网格对象**（否决）：20 行乘以每行可能的多个子网格，新增对象多得多，而且依赖 TMP 复用子网格的内部行为。
- **加嵌套 Canvas 脱离遮罩**（否决）：要开 overrideSorting，改变绘制顺序。
- **关掉排行榜的遮罩**（否决）：圆角依赖它。

**Consequences:**
- `level2` 成为被修改的文件，安装、备份、还原和已注入判定都覆盖它，从旧版本升级时自动补进备份。
- 所有语言的状态标签都从 Figtree 变成思源黑体 Black。拉丁字母由思源黑体提供；思源黑体没有的文字系统（如阿拉伯文）仍走后备和子网格，与原版现象相同。
- 这是第一次向 `resources.assets` 和 ui 包的字体集合新增对象。对象 path_id 紧接文件现有最大值。ui 包里的新对象没有登记到预制体的预加载表，靠引用按需加载。
- 显示效果无法自动测试，要进游戏确认。
