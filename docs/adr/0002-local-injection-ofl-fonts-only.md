# 仅在玩家本地注入、发布包只含自有 OFL 资源

**Status:** accepted；字体子集与注入方式由 ADR 0003 取代；发布包另含第三方 Python 运行环境，见 ADR 0007（仍不含任何游戏原始资源）

中文显示须向 TMP 主字体注入中文后备，而字体资源位于体积较大的 `ui_assets_all` 包中。若预先打好补丁发布，等于再分发 Funselektor 的 UI 美术资源，构成侵权。因此安装器仅在玩家本地读取其游戏文件并注入；GitHub 发布包与 Steam 工坊物品只包含自有资源（中文字体与译文），不含任何游戏原始资源。

字体仅用可公开再分发的 SIL OFL 字体，界面统一采用思源黑体（Noto Sans CJK SC），因其字形覆盖最全、风格中性、无需叠加兜底字体。否决商业字体（如方正美黑）：其授权不允许随免费公开 MOD 再分发，且维权风险高；显示字体得意黑因覆盖偏窄亦未采用。

**Consequences:**
- 仅本地注入，安装器须在玩家机器上重打体积较大的 `ui_assets_all` 包，较慢且需容错。
- 字体 SDF 图集按译文实际用字做静态子集，补繁体时须扩子集重烘。
